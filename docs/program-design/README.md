# Program Designs

Create construction-ready program designs from
`docs/templates/PROGRAM-DESIGN.md` and use the next available
`PROGRAM-DESIGNNNNN` number. A program design normally covers one coherent
capability and must be Accepted before it is used as an implementation-plan
input.
